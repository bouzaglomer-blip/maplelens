# Security policy

## Reporting

Report privately through this repository's **Security** tab →
**Report a vulnerability**. Please don't open a public issue.

## In scope

- Security bugs in MapleLens.
- **Anything that could get players banned**: code, a dependency, or a
  behavior that breaks the screen-only rule (reading or writing game memory,
  touching game files or network traffic, or sending input to the game).

We treat both the same way: a fix comes first, then a public note once it's safe.

## Supported versions

Only the latest commit on `main` until the first release.
