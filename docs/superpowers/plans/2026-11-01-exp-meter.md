# EXP Meter + Shared Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running `uv run maplelens` that shows a draggable box over the game with EXP/min, %/min and time to level, and a history window of average EXP/min per map + class + level, kept across days.

**Architecture:** A 2 Hz Qt timer grabs the game window's client area (`capture.py`). It runs four pure readers once per frame (`readers/`) into a `Reading`, then hands that to the EXP meter tool. The tool's pure logic (`meter.py`) turns readings into a live rate and saved segments (SQLite). Its Qt side shows a box and a table on top of a click-through layer (`overlay.py`). Readers locate UI anchors by template search, so nothing depends on resolution.

**Tech Stack:** Python 3.12, uv, ruff, pytest; `mss`, `numpy`, `opencv-python-headless`, `PySide6`; stdlib `sqlite3`, `json`, `ctypes`.

**Spec:** `docs/superpowers/specs/2026-11-01-exp-meter-design.md`. Read it first. This plan points at its sections instead of repeating them.

**Deviations from the spec's sketch (both minor):**
- The spec drew `capture/` and `overlay/` as folders. Here they're single modules (`capture.py`, `overlay.py`) until they outgrow one file.
- The spec had `grab.py` save the reader crops. It saves full frames only, because crops need the anchor templates, and those are cut *from* the first grabs. The implementer cuts the fixture crops in Tasks 5–6.

## Global Constraints

- Screen-only rule (`AGENTS.md`). `uv run python scripts/check_screen_only.py` must pass after every task. Don't write banned module or Win32 names anywhere under `src/` or `scripts/`, comments included.
- Runtime deps: exactly `mss`, `numpy`, `opencv-python-headless`, `PySide6`. Use **headless** OpenCV, because the regular wheel bundles its own Qt and breaks PySide6. Add each one in the task that first imports it.
- Window-geometry calls via `ctypes` only: `EnumWindows`, `GetWindowTextW`, `IsWindowVisible`, `IsIconic`, `GetClientRect`, `ClientToScreen`, `SetProcessDpiAwarenessContext`. Nothing else from user32/kernel32.
- No global hotkeys. MapleLens windows never take focus from the game: boxes use `Qt.Tool | Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.WindowDoesNotAcceptFocus`.
- Values from the spec: capture every **500 ms**; rolling window **300 s**; idle cutoff **90 s**; jump = gain > **5×** median of recent gains, only once **≥10** gains are known; open segment flushed every **60 s**; a value counts only once seen on **2 consecutive frames**.
- Data dir: `%APPDATA%\MapleLens\`. Files there: `maplelens.db`, `settings.json`, `grabs\`. Full-frame grabs **never** go in the repo; they contain names and chat.
- Fixtures: `tests/fixtures/screens/<reader>_<case>_<W>x<H>_100.png`, cropped to the anchor + value only, never including the character-name line, chat or other players. The owner reviews each before commit.
- Line length 100, ruff rules `E,F,I,UP,B` (existing `pyproject.toml`).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on the current branch; never push.

## Review Focus

1. **Game window moved or resolution changed mid-session.** The cached anchor position goes stale, and the reader must find the new spot, not return `None` forever. → `test_find_anchor_recovers_after_move` (Task 5).
2. **A read caught mid-animation or half covered** (`23,6` or `81.4` only). This must return `None`, never a wrong number. → `test_exp_partial_text_is_none` (Task 5).
3. **Death, then respawn in town in the same couple of frames.** The loss must not count and must not be credited to the town. → `test_death_then_map_change_counts_nothing` (Task 2).
4. **Game minimized or map unreadable for a while, then back on the same map.** That stretch must add no active time, even when it's shorter than 90 s. → `test_paused_stretch_adds_no_active_time` (Task 2).
5. **Killed mid-grind and restarted.** History keeps the flushed part of the segment, and a re-flush of the same segment replaces the row, not doubles it. → `test_resave_same_segment_replaces` (Task 3).

### Task 2: EXP meter logic (pure)

**Files:**
- Create: `src/maplelens/readers/__init__.py`, `src/maplelens/tools/__init__.py`, `src/maplelens/tools/exp_meter/__init__.py`, `src/maplelens/tools/exp_meter/meter.py`
- Test: `tests/test_meter.py`

**Interfaces:**
- Produces, `readers/__init__.py` (only types for now; `read_all` comes in Task 6):
  - `@dataclass(frozen=True) ExpValue: raw: int; pct: float`
  - `@dataclass(frozen=True) Reading: t: float; exp: ExpValue | None; level: int | None; job: str | None; map_name: str | None`
- Produces, `meter.py`:
  - `@dataclass Rate: exp_per_min: float; pct_per_min: float; minutes_to_level: float | None`
  - `@dataclass Segment: start: float; end: float; map_name: str; job: str; level: int; exp: int; pct: float; active_s: float`
  - `class ExpMeter(idle_cutoff_s: float = 90, jump_factor: float = 5, window_s: float = 300)`, with these methods:
    - `.feed(r: Reading | None) -> None`, where `None` means no frame.
    - `.rate(now: float) -> Rate | None`
    - `.pop_closed() -> list[Segment]`
    - `.open_segment() -> Segment | None`
    - `.close(now: float) -> None` closes the open segment, for app exit.

Algorithm for `feed`, which neither the signatures nor the tests determine:

```
confirm each field (exp, level, job, map_name) separately: the field's
  confirmed value changes only when the same raw value (None included) arrives
  on 2 consecutive feeds. feed(None) = a reading with every field None.
order within one feed: (1) exp change, credited to the segment that is open
  now (so a level-up's wrap goes to the old level), then (2) closing/opening.
(2) on a confirmed change of map_name, job or level: close the open segment
  (if any) and clear last_event_t. Then, if map, job and level are all
  confirmed non-None and there's no open segment, open one at r.t.
(1) on a confirmed exp change (old -> new, both non-None):
  level went up            -> gained = (100 - old.pct) + new.pct;
                              raw = (old.raw / (old.pct/100) - old.raw) + new.raw
                              (just new.raw if old.pct == 0)
  same level, new < old    -> death: count nothing
  level unknown or down    -> count nothing
  gain > jump_factor * median(last 50 counted pct gains), with ≥10 known
                           -> jump: count nothing
  else                     -> counted gain
  counted gains go into the rolling list (t, raw, pct), whatever the map.
  if a segment is open: gap = t - last_event_t (if set); if gap <= idle_cutoff_s,
    active_s += gap. Counted gains also add raw/pct to the segment.
    last_event_t = t, and segment.end = t.
any feed where map_name's confirmed value is None, or that has no frame:
  close nothing, but clear last_event_t (accrual paused).
```

Mark the level-up rule with `# ponytail: level-up needs the level and the % drop to confirm on the same feed; a level misread at that moment counts the wrap as a death. Look at the level one feed later if that shows up.` The spec also lists "idle gap" as a reason to close a segment. That's skipped here because an uncounted gap already does the job, and grouping is by map + class + level anyway.

`rate(now)`: sum the gains in the last `window_s`, divided by `min(window_s, now - first_feed_t) / 60`. Return `None` if under 60 s since the first feed. `minutes_to_level = (100 - current pct) / pct_per_min` when `pct_per_min > 0`, else `None`.

### Task 5: Anchor search, glyph reading, EXP + level readers

**Needs the owner's grabs from Task 1.**

**Files:**
- Create: `src/maplelens/readers/glyphs.py`, `src/maplelens/readers/exp.py`, `src/maplelens/readers/level.py`, `src/maplelens/readers/templates/` (PNG anchors and glyphs), `tests/fixtures/screens/exp_*.png`, `tests/fixtures/screens/level_*.png`
- Test: `tests/test_glyphs.py`, `tests/test_readers.py`

**Interfaces:**
- Produces, `glyphs.py`:
  - `load(name: str) -> np.ndarray` loads `templates/<name>.png` as BGR, cached.
  - `BASE_H = 768`. `normalize(frame) -> np.ndarray` resizes a full game frame to height `BASE_H`, keeping the aspect ratio (`cv2.INTER_AREA`), and returns frames already at that height unchanged. The game scales its whole picture with the window, so readers always work at the 1366x768 scale. Only `read_all` (Task 6) calls it, once per frame. Readers take an already-normalized frame.
  - `find_anchor(frame, name: str, threshold: float = 0.9) -> tuple[int, int] | None` searches the whole frame and returns the top-left of the best `cv2.matchTemplate` (`TM_CCOEFF_NORMED`) match at or above `threshold`. It keeps a module-level cache of the last hit per name and checks that spot first. The result for a given frame is the same with or without the cache.
  - `mask(img, lo: tuple[int, int, int], hi: tuple[int, int, int]) -> np.ndarray` returns a bool mask of pixels with BGR inside `[lo, hi]`.
  - `read_text(m: np.ndarray, font: str, space_px: int) -> str | None` splits the bool mask into glyphs on empty columns, crops each glyph to its rows, and matches it against every `templates/<font>/*.png` mask of the same shape by fewest differing pixels. A glyph within ±1 px of a template's size counts as matching; compare at the template's size. Returns `None` if any glyph has no template within the tolerance. The default is 10 % differing pixels; loosen it only as far as the rescaled 1920x1080 and 2560x1440 fixtures need, and name it as a constant. A column gap ≥ `space_px` becomes a space. Glyph filenames are the character, except `comma`, `dot`, `pct`, `lbr`, `rbr`, `slash`, `lt`, `gt` (map names can contain `<Bonus>`).
- Produces: `read_exp(frame) -> ExpValue | None`, which reads relative to anchor `exp_label`. It parses `^([\d,]+)\[(\d{1,3}\.\d\d)%\]$`, returns `None` unless `0 <= pct < 100`, and strips commas.
- Produces: `read_level(frame) -> int | None`, which reads relative to anchor `lv_label`. Orange-digit colour range. Returns `None` unless `1 <= level <= 200`.
