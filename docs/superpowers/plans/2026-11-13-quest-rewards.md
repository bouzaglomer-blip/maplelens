# Quest Rewards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every quest the Quests tab shows gets a one-line reward summary (EXP · mesos) that opens to its items (as icons), citizenship contribution and the rest of its chain.

**Architecture:** The rewards ship as data: `quests.json` gains per-quest `rewards`, `chain`, `after`, and `data/item_icons/` holds one PNG per reward item. A new pure module `tools/quest_helper/rewards.py` turns a quest into the summary text and detail groups. `ui.py` adds three item kinds to the tab's item list and one setting for open/closed.

**Tech Stack:** Python 3.12, PySide6, pytest, uv. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-13-quest-rewards-design.md`

## Global Constraints

- Screen-only rule (`AGENTS.md`): nothing new is read from the screen; nothing is fetched at runtime, icons included.
- No new dependency. Don't change `version` in `pyproject.toml`.
- Don't write the guard's banned module or Win32 names in comments or docstrings under `src/` or `scripts/`.
- Each tool depends only on readers + overlay: `quest_helper` must not import from another tool.
- Rows and buttons keep `Qt.NoFocus`; nothing takes the game's keyboard.
- Closed, the rewards add exactly one line per quest that shows rows; collapsed tracked headers get nothing.
- Numbers with thousands separators (`f"{n:,}"`): `7,020 EXP · 1,140 mesos`.
- Exact copy: `You pick 1 of:`, `Random, 1 of:`, `For your class:`, `By class:`, `{town} contribution +{n}` / `+{lo}–{hi}` (en dash), `Rest of chain ({n} quests): +{exp} EXP · {mesos} mesos` (`1 quest` when one), ▸ closed, ▾ open.
- Setting `quest_rewards_open`, default `False`, one value for every quest.
- Every commit: `uv run pytest`, `uv run ruff check`, `uv run ruff format`, `uv run python scripts/check_screen_only.py` pass.

## Review Focus

1. **The job reads None on some ticks** (OCR miss): class items must not flicker between `For your class:` and `By class:` — keep the last job read. Test in Task 3.
2. **A reward item with no icon file** (meowdb-only items): an empty slot with the name beside it, no crash. Test in Task 3.
3. **A quest with no rewards at all**: no reward line, nothing else changes. Test in Task 3.
4. **The player drags the tab wider** (`set_tab_w`, up to 480): an icon row fits more icons; nothing overflows at 214. Test in Task 3.
5. **A redraw every tick**: `_render` compares item tuples; the reward items must compare equal tick to tick (plain tuples of str/int), or the tab rebuilds every tick. Test in Task 3.

**Interfaces:**
- Produces, in `data.py`:
  - `ICONS: Path` = `Path(__file__).parents[2] / "data" / "item_icons"`
  - `@dataclass(frozen=True) class Reward: item: int; count: int; kind: str; cls: str | None = None; gender: str | None = None` — `kind` is `"always" | "pick" | "random"`; `cls` one of `Beginner, Warrior, Magician, Bowman, Thief`; `gender` `"male" | "female"`.
  - `@dataclass(frozen=True) class Rewards: exp: int = 0; mesos: int = 0; items: tuple[Reward, ...] = (); contribution: tuple[str, int, int] | None = None` — `(town, low, high)`, `low == high` for a fixed amount.
  - `Quest` gains, **after** its current fields so tests that build `Quest(...)` positionally keep working: `rewards: Rewards = Rewards()`, `chain: str | None = None`, `after: tuple[int, ...] = ()` (prerequisite quest ids in the same chain).
  - Reward items are entries of `QuestData.items` (name, `drops=()`, `shops=()` when only a reward).

**JSON shape** (per quest, keys omitted when empty; the file stays one line, `sort_keys=True`, as now):
`"rewards": {"exp": 7020, "mesos": 1140, "items": [[4010000, 7, "random", null, null], ...], "contribution": ["Henesys", 100, 325]}`, `"chain": "Rowen the Fairy and the Cursed Doll"`, `"after": [10201]`.

  - Join: our id → OSMS id; except `10613→10617, 10614→10618, 10615→10619, 10616→10620` (same name). Ids `10600–10604, 10607–10612` come from meowdb.

Item rewards: `guaranteed: true` → `"always"`; else `"pick"` if the id is in the quest's `reward_choices` groups, else `"random"`. Keep `classes[0]` (all have one) and `gender`.

  - Chain: OSMS `chain`; `after` = the quest's `requirements` of `type: "quest"`, mapped back to our ids (10617–10620 → 10613–10616), kept only if that quest has the same chain name.
  - Every reward item id gets an `items` entry: name from OSMS `items.json`, else meowdb's `name`.
  - Icons: for each reward item id with an OSMS `icon_url`, save the PNG as `item_icons/<id>.png` (id without leading zeros).

### Task 2: Reward logic (pure)

**Files:**
- Create: `src/maplelens/tools/quest_helper/rewards.py`
- Test: `tests/test_quest_rewards.py`

**Interfaces:**
- Consumes: `Quest`, `QuestData`, `Reward`, `Rewards` from Task 1.
- Produces, in `rewards.py`:
  - `BRANCH: dict[str, str]` — every name in `readers.job.JOBS` → its branch (spec's "Class branch" table; `Rogue` → `Thief`, `Wizard (Fire, Poison)` → `Magician`, …).
  - `branch(job: str | None) -> str | None`
  - `@dataclass(frozen=True) class Shown: item: int; name: str; count: int; tip: str` — `tip` is the hover text: `name`, `" ×{count}"` when count > 1, `" ({cls})"` when listed by class, `" ({gender})"` when gendered.
  - `@dataclass(frozen=True) class Group: label: str; items: tuple[Shown, ...]` — `label` `""` for always-items.
  - `summary(data: QuestData, quest: Quest) -> str`
  - `details(data: QuestData, quest: Quest, branch: str | None) -> tuple[Group | str, ...]` — groups and text lines in the spec's order.
  - `chain_rest(data: QuestData, quest: Quest) -> list[Quest]`

**Rules the tests pin** (the spec's "The closed line" and "The details"):
- `summary`: `"7,020 EXP · 1,140 mesos"`; only one of them if the other is 0; neither → the first group's text (`"Blue Potion ×15"` for one item, `"{n} items"` for more), else the contribution line, else `""`.
- `details` order: always-items group (non-class, label `""`), pick group (`You pick 1 of:`), random group (`Random, 1 of:`), class group, contribution line, chain line. Empty groups are left out.
- Class items (any kind) go to the class group only. Known branch: keep that branch's items, label `For your class:`. Unknown: all of them, label `By class:`, `tip` names the class.
- Chain: quests with the same `chain` whose `after` reaches `quest.id`, directly or through each other (walk with a visited set). Line only when that list is non-empty.

### Task 3: The reward line in the Quests tab

**Files:**
- Modify: `src/maplelens/tools/quest_helper/ui.py`
- Modify: `src/maplelens/store.py` (`DEFAULTS["quest_rewards_open"] = False`)
- Test: `tests/test_quest_ui.py`

**Interfaces:**
- Consumes: `summary`, `details`, `branch`, `Group`, `Shown` (Task 2); `ICONS` (Task 1).
- New items in `_items()` (plain tuples, so `_render`'s equality check holds):
  - `("reward", text, opens, open)` — right after the `"open"` line, and right after an expanded `"head"`; left out when `summary` is `""`.
  - `("detail", text)` — a wrapped grey line, indented.
  - `("icons", label, items)` — `items` a tuple of `Shown`.
- `QuestHelperTool._flip_rewards() -> None` — flips `settings["quest_rewards_open"]`, then `_save()`.

**How it draws** (spec "The closed line", "Items, layout A"; mockup is the reference look):
- Reward line: a flat `mark_button` like the tracked header (left-aligned, `LABEL_PT`), text `"▸ " + text` / `"▾ " + text` when `opens`, else just `text` and no click. Cut with `_fit` to `self._tab_w - BAR`.
- Indent details 13 px. Detail text: `text_label(..., LABEL_PT, LABEL_COLOR)` with `setWordWrap(True)`.
- Icon slot: a small `QWidget` subclass, 26×26, fill `HERE_BG`, radius 4, the icon centred at its own size (scaled down only if over 24 px), the count bottom-right in bold 7 pt white when > 1, tooltip `Shown.tip`. Pixmaps cached per item id (`functools.cache`); a missing file → empty slot.
- A group of 1–2 items: each on its own line, slot + `name ×count` label. Three or more: the label line, then slots in a `QGridLayout`, `cols = (self._tab_w - BAR - 13) // (26 + 3)`.
- `update()` keeps the last non-None `r.job` in `self._job`; `_clean()` turns a non-bool `quest_rewards_open` into `False`.
